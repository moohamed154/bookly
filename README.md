# Bookly

A book-exploration app built on the free Google Books REST API.

Browse featured and newest books, search the full Google Books catalog, and
open book details with cover art - with explicit loading, success and error
states throughout.

## Features

- Search and browse the Google Books catalog
- Book details with high-resolution covers
- Smooth scrolling via image caching and asynchronous fetching

## Tech Stack

Flutter - Dart - BLoC/Cubit (flutter_bloc) - Dio (REST API) - MVVM - get_it
(dependency injection) - go_router - cached_network_image - dartz
